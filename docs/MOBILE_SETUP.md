# HILLO Android / iOS shell

The existing root `index.html` remains the GitHub Pages web entrypoint. The native app uses `www/`, generated from the existing site by `npm run build:web`. Do not edit `www/` directly.

Requires Node 22+, Android Studio/SDK for Android, and macOS/Xcode for iOS.

```bash
npm install
npm run build:web
npx cap add android
npx cap sync android
npx cap open android
```

On macOS, use `npx cap add ios`, `npx cap sync ios`, `npx cap open ios`.

The reverse-domain app ID `com.hillo.app` is provisional; confirm before first store release. Existing Supabase login redirects and native deep-link handling must be tested before release. No APK/AAB/IPA is generated by these source files alone.
