# HILLO V0.8 Preview
Mobile-first public marketplace preview for HILLO.

## GitHub Pages
Upload `index.html`, `manifest.webmanifest`, and the `assets` folder to the repository root. Do not upload only the ZIP file if you want GitHub Pages to render the site.

## Included
- New HILLO branding/logo
- Public homepage (no forced login)
- PLZ nearby-helper search preview
- Service categories
- Helper cards with distance/rating/price
- Contextual login/register modal
- Existing Supabase Auth connection
- Responsive mobile/desktop UI
- PWA manifest

Note: Nearby results are visual/demo data in this preview. Real PLZ-distance queries, profiles, tasks, booking and payments still need database implementation.
